# Workflow C Detailed Technical Doc (AI Real-Person Voiceover Commerce)

> SKILL.md already gives the "in plain words" explanation and current availability notes. This file is the detailed technical reference for the **complete 5-stage pipeline** + **overlay composition plan** + **digital-human connection**.

---

## Positioning

- **Input**: product multi-angle video / images
- **Output**: a **real-person host (can come from a reference photo the user provides, or an AI-generated virtual host)** doing a voiceover introducing the product in a specified scene (livestream room etc.)
- **Fundamental difference from A/B**: A/B's input core is "face / motion", **C's input core is "product"**; C's host identity **defaults to an AI-generated virtual host; if the user provides a host reference photo, that photo is used as the on-screen person identity source for the voiceover**

## Stage C0: Requirement Parsing & Material Ready

### 1. Parse user natural language → extract 5 elements

| Element | Example |
|------|------|
| Product category | Mouthwash / cosmetics / digital product |
| Scene | Livestream room / desktop / outdoor |
| Persona | Female host / young male host / senior explainer |
| Shot size | Half-body / close-up / full-body |
| Selling-point focus | Function / price / emotion / comparison |

Example: "A woman introduces this mouthwash in a livestream room" → product=mouthwash; scene=livestream room; persona=female host; shot size=half-body; selling point=to be extracted in C2

### 2. Host Identity Source Determination (key)

- **User provides host reference photo** → that person is the on-screen person of the voiceover video (face + overall look per B-0 confirmation). This photo serves as:
  ① Image source for lip-sync digital human (Tencent Zhiying / HeyGem)
  ② ID-lock source for multi-reference generation (Seedance/Kling)
- **No photo provided** → AI generates a virtual host, persona set by the C2 persona library per requirements

### 3. Material ASCII-ization

Copy product multi-angle video to an **ASCII filename** (e.g. `product_raw.mp4`). ⚠️ Same pitfall as A/B: cv2 can't read Chinese paths.

## Stage C1: Product Asset Extraction

```bash
python scripts/product_extract.py \
  --video product_raw.mp4 \
  --out product_images/ \
  --count 5                # extract 5 reference images
```

Automatically picks a product reference image set that is [clear + front-lit + varied angles].

## Stage C2: Scene Recommendation + Persona Matching

- Scene recommendation: AI **actively recommends 2-3 candidates** based on product category and user / customer needs, user picks from them (decision gate C-2)
- Persona library: match by gender / age / style / clothing

## Stage C3: Voiceover Script Generation

Input: product image + scene + persona + selling points
Output: four-part script (opening hook → pain-point intro → product intro → call to action)

## Stage C4: Overlay Composition + Digital-Human Lip-Sync

### Plan 1 (recommended): real product overlay composition + AI person scene

- Key showcase shots use the **real product image** the user uploaded for overlay / composition (keep logo, text 100% undeformed)
- Person / scene / motion generated by AI
- ⚠️ **Current status**: plan is documented, **needs the user to actually run real product video to spot-check overlay seams** (current environment can't read images, not verified end-to-end visually)

### Plan 2: TTS voiceover + lip-sync digital human

- Copy → TTS human voice → drive host lip-sync
- Recommended channel: Tencent Zhiying (SaaS, needs account) or open-source HeyGem (can deploy locally)
- ⚠️ **Current status**: needs platform account / local deployment, **this skill does not include the lip-sync digital human implementation itself**

## Stage C5: Final Acceptance

- Product consistency: is logo / text / bottle / packaging deformed
- Voiceover sync: is lip-sync aligned with audio
- Duration: matches expectation

## FAQ

**Q: My logo is always deformed, what to do?**
Plan 1's "overlay composition" is designed to solve this - the real product image is overlaid into the AI scene, logo undeformed. See Stage C4 Plan 1.

**Q: Do digital-human platforms cost money?**
- Tencent Zhiying: SaaS, charged by usage
- HeyGem: open-source free (needs compute / deployment)
- Which to pick depends on budget and technical ability

**Q: Can I use it without a host reference photo?**
Yes, AI generates a virtual host (persona matched by the C2 persona library per requirements). But the effect is usually worse than providing a real reference photo.
